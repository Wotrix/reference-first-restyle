# Reference-First Restyle · 先参照，后代码

给 AI 编码代理用的一个 Skill：改界面之前，强制走「参照 → 规格 → 候选 → 实现 → 验收」的顺序。

它治的是一个常见病：AI 写的界面能用，但丑。多数时候不是模型不行，是你没给它参照——「高级一点」「现代一点」「有设计感」这类词在模型那里约等于什么都没说，没有参照时它只能回你训练数据的平均值。

## 它是什么、不是什么

它是一套**流程纪律**，不是审美规则，也不是组件库：

- 不负责告诉你什么是好看的（那是 taste 类 skill 的事）；
- 不提供任何现成代码；
- 只负责保证：没有参照不许动手，没有可执行规格不许写形容词，没有候选方向不许写代码。

和 taste skill 互补：taste 定标准，这个定顺序。单独用也成立——有参照，就有下限。

## 五步分别做什么

**1. 找参照（0 参照不动手）** 你手头的截图最高优先；其次是网上的组件页和图库（页面 URL 加 `.md` 常能拿到 AI 可读的结构化描述）；最后是项目自己的既有模式——先对齐一致，再谈新方向。参照也要质检：拖窄窗口看移动端、看带不带交互、看依赖多少，不过关就换。

**2. 蒸馏成规格，不是形容词** 把参照翻译成机器可执行的条目。上面两张定价区的差别就是这么来的：

```text
❌ 「更现代一点，有高级感」

✅ 标题左对齐 22px/600，不用渐变字
   卡片圆角 16px，阴影 0 1px 2px + 0 10px 28px rgba(31,35,40,.07)（带底色色调）
   价格 32px/600，font-variant-numeric: tabular-nums
   强调色只用一个 #0e7c66，只出现在勾选图标上；推荐档用暗色卡区分，不用徽章胶囊
   每卡一个主操作，次操作降级为安静按钮；按钮底线对齐
```

每一条都必须能对应一行具体的 CSS 或一个结构决定——规格里出现「高级感」即为不合格。

**3. 候选先行** 一次给 2-3 个方向，每个说清：改了什么、差在哪、风险在哪。你选定后才写代码。AI 最大的浪费不是写得慢，而是写完一版你不敢用。

**4. 三约束实现** 数据结构与 props 不动；不引入新依赖；出完整文件不给 diff。外部参照只取设计、不取代码——按项目自己的技术栈和数据结构重写。

**5. 验收** 构建通过只是及格线。「看起来没问题」不是没问题。

## 怎么调用

**最常用：说人话。** 装好后正常提需求，描述里的触发词（改观感 / 照着参考图做 / 美化现有页面）会自动匹配：

- 「这个页面太丑了，改观感」→ 它会先找参照、给候选，而不是直接动手
- 「照着这张参考图重做这个面板」→ 发图即可，它把图蒸馏成规格再动手
- 显式调用：`/reference-first-restyle`

**参照从哪来：**

- 你手头的截图、设计稿——直接发给它
- 组件超市（如 21st.dev）——按用途找分类（定价→Pricing、后台→Dashboard UI），页面 URL 加 `.md` 就是一份 AI 可读的结构化描述
- 你的项目本身——已经长成的同类组件就是现成参照

**完整的显式模板**（不靠触发词时直接粘）：

```text
这次改的是现有页面的观感，不是重写。
参照：<截图已发 / 链接 https://...（会加 .md 读结构化描述）/ 按项目里 XX 组件的风格>
现有文件：<路径或代码>
技术栈：按项目已有的来，不升级、不引入新依赖
约束：
1. props 名称、数据字段、组件层级一律不动，只改布局/间距/字号/颜色/圆角/阴影/动效
2. 先给 2-3 个方向（各改了什么、差异、风险），我选定后再写代码
3. 出完整单文件，不给 diff
验收：功能不变，构建能过，我过目。
```

**接了 21st.dev 类 MCP 的话**（可选加成）：让它「先用 search / get_inspiration 收窄候选，只给名字和链接，等我确认再取一个」。免费工具收窄范围、付费一次只取一个；取到的代码也不照抄——只取设计，按你的技术栈重写。

## 安装

把 `SKILL.md` 放进代理的技能目录即可，单文件、无依赖：

```bash
# 项目级（仅当前项目生效）
mkdir -p .agents/skills/reference-first-restyle
curl -fsSL -o .agents/skills/reference-first-restyle/SKILL.md \
  https://raw.githubusercontent.com/Wotrix/reference-first-restyle/main/SKILL.md
```

全局安装则放到 `~/.agents/skills/reference-first-restyle/`。适用于支持 skills 机制的编码代理（ZCode、Claude Code 等）。
